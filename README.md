# Travel Planner — Путевой план

[Открыть демо](https://travel-planner-liard-alpha.vercel.app)

Редактор маршрута путешествия на React и TypeScript. Поездка состоит из дней, а каждый день — из шагов: завтрак, поездка на поезде, прогулка. Редактор собирает шаги в расписание и сохраняет маршрут в браузере, чтобы к планированию можно было вернуться после перезагрузки страницы.

## Как попробовать

1. Чтобы пройти пример на русском, откройте **Settings → App language**, выберите **Русский** и вернитесь в «Маршрут».
2. Нажмите на название маршрута и переименуйте его.
3. Нажмите «+», создайте день и укажите дату. Добавьте сначала прогулку на 14:00, затем завтрак на 09:00. К одному из шагов добавьте стоимость или заметку.
4. Сохраните день. В карточке завтрак появится перед прогулкой, а заполненные детали — под описанием шага. Шаги без времени располагаются в конце списка.
5. Дождитесь статуса «Сохранено» в шапке и обновите страницу. Название маршрута, день и его шаги восстановятся.

## Что реализовано

- Редактирование названия маршрута с подтверждением и отменой.
- Форма дня с добавлением и удалением шагов, вводом времени и выбором дополнительных полей.
- Карточки дней с датой, днём недели и хронологией шагов.
- Сворачиваемая боковая панель с подсветкой выбранного пункта.
- Автосохранение подтверждённых изменений и восстановление маршрута при запуске.

## Языки интерфейса

Доступны русский и английский. По умолчанию выбран английский. Язык можно сменить в разделе «Настройки → Язык приложения». Подписи меню, форм и кнопок обновляются сразу. В карточках уже сохранённых дней месяц и день недели отображаются на выбранном языке. Названия маршрутов, шаги и заметки отображаются так, как их ввёл пользователь.

В форме создания дня используется встроенный календарь браузера. Язык календаря и подсказка формата даты зависят от браузера и настроек устройства.

## Как устроено сохранение

Черновики находятся в локальном состоянии React. После подтверждения компонент отправляет действие в Redux Toolkit, а подписка на изменения маршрута ставит запись в IndexedDB в очередь. Статус «Сохранено» появляется после успешной записи актуальной версии. Переключение пунктов меню и сворачивание панели не запускают сохранение.

При запуске приложение сначала читает маршрут из IndexedDB и восстанавливает его в Redux, затем показывает редактор. Текущая версия хранит один маршрут в браузере на устройстве пользователя. Локальная версия и демо имеют отдельные хранилища. Очистка данных сайта удаляет сохранённый маршрут.

## Технологии

React, TypeScript, Redux Toolkit, React Redux, IndexedDB и Vite. Интерфейс свёрстан по макету в Figma с использованием CSS Grid, Flexbox и CSS-переменных. Демо размещено на Vercel.

## Локальный запуск

Понадобятся Node.js и npm. Из терминала выполните:

```bash
git clone https://github.com/DramaLam/travel-planner.git
cd travel-planner
npm ci
npm run dev
```

Откройте локальный адрес, который выведет Vite. Для проверки сборки и просмотра собранной версии:

```bash
npm run build
npm run preview
```
