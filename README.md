# Travel Planner

Редактор маршрута путешествия на React и TypeScript. Маршрут состоит из дней, а каждый день — из шагов: например, завтрака, поездки или прогулки. Карточка дня собирает их в расписание с временем, описанием и заметками.

## Что можно попробовать

1. Переименуйте маршрут и нажмите «+», чтобы создать день.
2. Введите название дня и выберите дату. Добавьте два шага, например прогулку в 14:00 и завтрак в 09:00.
3. Укажите стоимость или длительность одного из шагов и сохраните день. В карточке завтрак появится перед прогулкой, а заполненные детали — под названием и описанием шага. Шаги без времени идут в конце списка.

Пока форма открыта, в ней можно добавлять и удалять шаги. Кнопка отмены закрывает черновик. Сохранённые дни доступны до перезагрузки страницы.

## Как устроен редактор

- **React и TypeScript** — компоненты редактора и типы данных маршрута. Черновик дня хранится локально в форме.
- **Redux Toolkit и React Redux** — сохранённые дни. Форма отправляет действие добавления дня, редактор читает список из хранилища.
- **CSS и Figma** — карточки и формы по макету, общие цвета и шрифты заданы CSS-переменными.
- **Vite** — локальная разработка и сборка приложения.

## Запуск

Из корневой папки проекта выполните:

```bash
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминале. Для сборки и локального просмотра итоговой версии:

```bash
npm run build
npm run preview
```

## Ближайшие планы

Сохранять маршруты в IndexedDB, чтобы они открывались после перезагрузки страницы. Следующий этап — фотографии и файловые вложения к шагам.
